# Walmart Sales Analysis | Power BI

## Project Overview
This project analyzes Walmart sales data using Microsoft
Power BI to understand sales performance, profitability,
product performance, and return rates.

The interactive dashboard helps users explore business
performance across different products, cities, and dates.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Dashboard Features

- Total Revenue
- Total Transactions
- Total Profit
- Profit Margin
- Return Rate
- Monthly Revenue Growth
- Sales Performance by City
- Weekly Sales Trends
- Revenue vs Target
- Product Performance Analysis

## Key Business Questions

1. Which products generate the highest profit?
2. Which cities contribute to revenue?
3. How is revenue changing month over month?
4. How do actual sales compare with targets?
5. Which products have higher return rates?
